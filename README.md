## 📌 Projetos em Destaque

### 🏦 [Consórcio API](https://github.com/RonaldoSNavarro/consorcio-api)
Sistema backend de alta performance para administração e gerenciamento de consórcios, desenvolvido em **Java 21** com **Spring Boot 4**. Implementa regras de negócio financeiras reais baseadas nas normativas do Banco Central do Brasil (BCB) e Código de Defesa do Consumidor (CDC).

### 🖥️ [Consórcio Admin (Frontend)](https://github.com/RonaldoSNavarro/front_end_consorcio-api)
Módulo frontend de administração responsável por se conectar com o motor financeiro Spring Boot para gerenciar grupos, cotas, parcelas e assembleias.

### ☁️ Projeto AWS re/Start — Arquitetura Cloud
Migração e otimização da infraestrutura de e-commerce na AWS em equipe: **Amazon RDS (MySQL), S3, DynamoDB, AWS Lambda, API Gateway e ElastiCache (Redis)**.

### 🏥 [API Voll.Med](https://github.com/RonaldoSNavarro)
API RESTful em **Java / Spring Boot / PostgreSQL** para gestão de clínica de saúde com autenticação JWT, agendamento e gerenciamento completo de médicos e pacientes.
