## 🌟 Projetos Destacados

### [🏢 Consórcio API](https://github.com/RonaldoSNavarro/consorcio-api)
Meu projeto principal e mais complexo. Uma API robusta para administração de consórcios que segue as **normativas do Banco Central do Brasil (BCB)**.
- **Destaque:** Implementação de motor de contemplação com trava de integridade financeira (validação de saldo de Fundo Comum).
- **Features:** Fracionamento automático de parcelas, ciclo de vida de grupos (inauguração via AGO) e tratamento global de exceções para respostas HTTP padronizadas.

### [Conversor de Moedas](https://github.com/RonaldoSNavarro/challenge-conversor-de-moedas)
Aplicação em Java focada no consumo de APIs externas e manipulação de dados financeiros em tempo real.

### [ScreenMatch](https://github.com/RonaldoSNavarro/screenmatch)
Projeto desenvolvido para consolidar conhecimentos em Java OO, coleções e integração com banco de dados para gerenciamento de catálogos de entretenimento.
